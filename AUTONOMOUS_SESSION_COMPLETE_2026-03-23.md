- ✅ Created IPasskeyService interface (registration/authentication)
- ✅ Updated IAMDbContext with Credentials DbSet + configuration
- ✅ Build successful (0 errors)

**Credential Entity Features:**
- Public key storage (from authenticator)
- Sign counter (prevents replay attacks)
- AAGUID tracking (identifies authenticator model)
- Friendly names (e.g., "iPhone 15 Pro", "YubiKey 5")
- Device type hints (phone/computer/security-key)
- Backup eligibility & status (iCloud Keychain support)
- Transport tracking (USB, NFC, BLE, internal)
- Attestation certificate chain (optional device verification)
- Created/LastUsed timestamps

**Database Schema:**
```sql
CREATE TABLE Credentials (
  Id uuid PRIMARY KEY,
  UserId uuid NOT NULL,
  CredentialId bytea NOT NULL UNIQUE,
  PublicKey bytea NOT NULL,
  SignCounter integer NOT NULL,
  CredType varchar(50) NOT NULL,
  AaGuid uuid NOT NULL,
  Name varchar(200),
  UserAgent varchar(500),
  DeviceType varchar(50),
  IsBackupEligible boolean NOT NULL,
  IsBackedUp boolean NOT NULL,
  Transports text[],
  CreatedAt timestamp NOT NULL,
  LastUsedAt timestamp,
  AttestationFormat varchar(50),
  AttestationCertificate bytea,
  FOREIGN KEY (UserId) REFERENCES Users(Id) ON DELETE CASCADE
);

CREATE INDEX idx_credentials_userid ON Credentials(UserId);
CREATE UNIQUE INDEX idx_credentials_credentialid ON Credentials(CredentialId);
CREATE INDEX idx_credentials_userid_createdat ON Credentials(UserId, CreatedAt);
```
